# TeddyPups U.A.E. - Premium Teacup Puppies

A responsive, animation-rich website clone of TeddyPups U.A.E. Built with React 19, Vite, and React Router, featuring custom SVG character rigging, scroll-driven interactive scenes, dedicated subpages, and smooth inertia scrolling.

## Features

- Interactive Mascot Rig: Dynamic SVG poodle mascot with joint rotations, blinking eyes, expressive poses, and cursor tracking.
- Scroll-Driven Day-to-Night Scenes: Smooth gradient progression across 8 themed sections.
- Animated Page Transition Curtain: Custom diamond-quilted curtain with walking runner mascot on initial load and route changes.
- Interactive Cursor Trail: Custom paw pointer with directional footprint stamping that fades dynamically across the viewport.
- Dedicated Subpages:
  - `/puppies`: Filterable puppy catalog by breed and origin (Local / Imported) with direct WhatsApp enquiry buttons.
  - `/happy-families`: Polaroid photo wall featuring customer moments and heartfelt reviews.
  - `/how-it-works`: Step-by-step puppy adoption roadmap and delivery guide across the UAE.
  - `/faq`: Comprehensive question-and-answer resource covering veterinary checks, pickup, and care.
  - `/contact`: Showroom hours, Downtown Dubai address, and instant messaging actions.
  - `/gone-home`: Commemorative gallery of adopted puppies with their forever families.
- Horizontal Hall Scroll: Spring physics track in Meet the Pups with openable kennel doors.
- Flight Route Animation: Plane tracking along SVG bezier paths based on viewport scroll ratio.
- Step-by-Step Chat Mockup: Sticky mobile phone interface with live typing indicators and photo drops.
- Smooth Inertia Scrolling: Powered by Lenis for uniform scrolling behavior.

## Tech Stack

- React 19
- React Router 7
- Vite 8
- Lenis (Smooth Scroll)
- Dog CEO REST API (Live puppy imagery)
- CSS View Timeline animations & Custom Properties

## Getting Started

### Prerequisites

Node.js (version 18 or above recommended)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/RuchitAgrawal/InstaBiz-Task.git
   cd InstaBiz-Task
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
